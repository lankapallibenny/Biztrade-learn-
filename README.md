# BizTrade – Forex Lessons | ఫారెక్స్ లెసన్స్

**BizTrade** is a complete, interactive, bilingual (English + Telugu) Forex and Gold (XAUUSD) trading education platform featuring 50 illustrated lessons, procedural candlestick charts, interactive trading simulators, quizzes, and verifiable certificates of completion.

## 🚀 How to Enable GitHub Pages (One-Time Setup)

To make your site live on GitHub Pages:

1. Open your repository on GitHub: [github.com/lankapallibenny/Biztrade-learn-](https://github.com/lankapallibenny/Biztrade-learn-)
2. Click **Settings** (top navigation tab)
3. In the left sidebar, click **Pages** (under the "Code and automation" section)
4. Under **Build and deployment**:
   - **Source**: Select **GitHub Actions** (the repository includes an automated `.github/workflows/deploy.yml` workflow)
   - *Alternative*: Select **Deploy from a branch** → Branch: `main`, Folder: `/ (root)` → Click **Save**
5. Within 1–2 minutes, your live site will be live at:
   👉 **`https://lankapallibenny.github.io/Biztrade-learn-/`**

- **50 Comprehensive Lessons**:
  - Foundations: Forex basics, Currency pairs (Majors, Minors, Exotics), Pips, Lots & Leverage, Trading sessions.
  - Technical Analysis: Reading Candlesticks, Support & Resistance, Trends, Market Structure, Head & Shoulders, Triangles, Moving Averages, RSI, MACD, Bollinger Bands, Fibonacci Retracement, Pivot Points.
  - Risk Management & Psychology: Risk-Reward, Position Sizing, Stop Loss, Risk of Ruin, Trading Plans, Trading Journal.
  - Gold (XAUUSD) Corner: Dedicated practical section in every lesson tailored to Gold traders.
  - Bilingual Support: Instant 1-click toggle between **English** and **Telugu (తెలుగు)**.
- **Interactive Simulators & Tools**:
  - Engulfing & Candlestick Pattern Checker
  - Forex Session Clock (Sydney, Tokyo, London, New York)
  - Pending Order Checker
  - News Surprise Simulator (NFP, CPI, FOMC)
  - Gold (XAUUSD) Profit & Margin Calculator

  - Funded Challenge / Prop Firm Simulator

  - Procedural vector certificate with custom SVG seal

## 💻 Running Locally

To run the live site on your local machine:

```bash
# Clone the repository
git clone https://github.com/lankapallibenny/Biztrade-learn-.git
cd Biztrade-learn-

# Start the server (Node.js)
npm start
# or: node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.
